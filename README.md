# MiBiblioteca

MiBiblioteca es una propuesta de aplicación para gestionar y compartir
bibliotecas personales.

La aplicación permitirá a los usuarios organizar sus libros, indicar
si los han leído y compartir su biblioteca con amigos para facilitar
el préstamo y reutilización de libros.
